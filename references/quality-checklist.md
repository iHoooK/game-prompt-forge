# Проверка промпта холодным читателем

Перед выдачей перечитай готовый файл как исполнитель в пустой папке без доступа к чему-либо кроме текста. Отметь и исправь всё найденное. Если пункт нельзя проверить без пересчёта — пересчитай.

## Самодостаточность
- [ ] Нет ссылок на файлы, чаты, скиллы, которых у исполнителя не будет.
- [ ] Все термины введены (особенно придуманные: названия построек, ресурсов, секторов).
- [ ] Названия и числа везде одинаковы (то, что в таблице, совпадает с текстом и чек-листом).
- [ ] Референсы пользователя описаны словами.

## Решения и приоритеты
- [ ] Есть блок «Решения автора» (движок, стиль, длительность, переименования).
- [ ] Видно, что ядро, что желательное, что украшения; есть порядок «режь первым».
- [ ] Для франшиз: оригинальные имена и ассеты, а не заимствованные.

## Числа и достижимость (пересчитай)
- [ ] Каждый поток «производство/расход» согласован; узкие места задуманы и объяснены.
- [ ] Каждая покупка/разблокировка достижима: её стоимость не требует ресурса, получаемого только после неё; нет ресурсов, которые можно потерять безвозвратно.
- [ ] Суммарное время контента ≈ целевому (проведи грубый расчёт и укажи ожидание в тексте).
- [ ] Прогрессия не имеет тупиков: при любой разумной ошибке игрок может продолжить.
- [ ] Сложность нарастает постепенно; новое появляется регулярно.

## Проверяемость
- [ ] Для каждой системы можно написать тест по описанию.
- [ ] Определён отладочный API (имена методов) и сквозной сценарий.
- [ ] В чек-листе готовности каждый пункт имеет способ проверки.
- [ ] Бюджеты производительности указаны числами.
- [ ] Нет размытых слов без измеримого эквивалента («плавно», «красиво», «удобно»).

## Качество формулировок
- [ ] «Сердце» описано глубже периферии; меню и настройки — кратко.
- [ ] Правила объяснены причиной, а не только «обязательно».
- [ ] Образцы реплик (если есть сюжет) в нужном голосе.
- [ ] Нет списка запретов на полстраницы; запреты — только реальные ловушки.
- [ ] Язык и стиль единообразны; нет противоречий (например «без враждебности» и «босс-бой» без пояснения).

## Объём
- [ ] Размер соответствует размаху игры (аркада 2–4 тыс. слов, кампания 6–10 тыс.).
- [ ] Нет повторов одной мысли в разных блоках (заменены ссылкой «см. п. N»).

## Выдача
- [ ] Один файл `<имя-игры>-prompt.md`, UTF-8, цельный текст.
- [ ] Итоговое сообщение пользователю: путь, 5–8 строк решений, как использовать.
