# Ловушки окружения (из реального прогона)

Эти грабли наступали при сборке Oreflow. Вноси в промпт те, что подходят выбранному стеку, по одному предложению с причиной. Не копируй все подряд.

## Windows и shell
- Многострочные heredoc в bash ломаются на кириллице, апострофах и обратных кавычках. Файлы создавай инструментом записи файлов, а не shell-heredoc.
- Обратные слэши теряются при записи через shell/heredoc (пути Windows, регулярные выражения). Для кода с `\` пиши файл инструментом записи.
- Кодировка консоли может искажать кириллицу при чтении: читай файлы как UTF-8 явно.

## Зависимости и сборка
- Установка пакетов без версий приносит свежие мажорные версии. После `npm install` прочитай реальные версии (`npm ls`) и закрепи их в `package.json`, иначе сборка и типы разъезжаются.
- Для e2e на TypeScript нужны типы Node (`@types/node`) и их подключение в `tsconfig`.
- Если сборка запускает проверку типов, любая ошибка типов валит тест-сервер (`webServer` в Playwright). Сначала исправь типы.
- В Vite `base: './'` обязателен для itch.io и подпапок; проверь, что шрифты из CSS переписаны в относительные пути.
- Заархивированный билд проверь командой просмотра списка: `index.html` должен лежать в корне архива, а не в папке `dist/`. Встроенные архиваторы Windows иногда кладут корневую папку.
- Библиотека архивирования может поменять API между версиями; для zip надёжнее системная команда.

## Автоматические проверки и скриншоты
- Для WebGL в headless-Chromium (Playwright) нужны флаги программного рендеринга (`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`).
- Страница в скрытой вкладке получает троттлинг `requestAnimationFrame`; для замеров FPS и скриншотов используй видимое окно или headless-скрипт, а не вывод по «кадрам в секунду» из фоновой панели.
- Первый кадр включает компиляцию шейдеров и намного медленнее остальных: замеры делай после прогрева.
- Горячая перезагрузка dev-сервера сбрасывает состояние игры. Для проверки сцены напиши скрипт, который поднимает нужное состояние через отладочный API и делает скриншот.
- Для сквозного теста сначала пройди путь руками через настоящий ввод (хотя бы начало), остальное — отладочным API; иначе тест не проверяет управление.

## Игровая логика
- Если сцена показывает сюжетные/модальные окна поверх меню, следи за порядком `z-index`: окна меню оказывались под оверлеем и не кликались.
- Не пускай Esc одновременно закрывать окно и открывать паузу: последовательность нажатий в тесте должна учитывать, что делает каждое.
- Предметы на конвейере и подобные потоки: считай каждый предмет в тесте сохранности (в мире + буферах + принятое = выпущенное), включая снос и перестройку.
- Статические декорации, которые выглядят препятствиями, должны либо блокировать, либо не стоять там, где игрок строит; иначе тесты и игроки упираются в «невидимые» запреты.
- Декоративные объекты, добавленные после тестов, ломают координаты в тестах; держи тестовые участки карты свободными.

## Производительность
- Отрисовка тысяч одинаковых объектов — инстансингом; статические меши одной постройки склеивай по материалам; крупные статические скопления (скалы) режь на куски для отсечения по пирамиде видимости.
- Малополигональные скругления дешевле: при большом числе экземпляров выбирай минимальное разбиение.
- Метрики вызовов отрисовки и треугольников при постобработке смотри суммарно за кадр (отключи автосброс счётчика).

## Ассеты
- Скачанный ассет без проверки лицензии на его странице может оказаться «только для личного использования» или с условиями, несовместимыми с публикацией. Открывай страницу и записывай лицензию в `assets.json`.
- Паки из разных источников выбиваются по палитре, масштабу и ракурсу. Перед подключением собери контактный лист и убери выбивающееся.
- Сайты с аккаунтом (Freesound, Mixamo) нельзя скачивать автоматически без входа; не трать на них время, бери то, что доступно напрямую.
- Спрайты с непрозрачным фоном, разным размером тайла и неверной точкой привязки ломают отрисовку: нормализуй размер, фон и pivot при импорте.
- Сгенерированное изображение смотри глазами до подключения: артефакты, текст на картинке, непрозрачный фон встречаются часто.
- Файлы ассетов в билде должны открываться по относительным путям (в том числе из zip на itch.io).

## Звук
- Синтез звука кодом звучит как прототип; основа это готовые сэмплы и треки.
- Исполнитель не слышит звук: в промпте требуй проверки программной (нет исключений, громкости в допустимых пределах, нет клиппинга по пиковому уровню) и честно пиши в отчёте, что на слух не проверено.
- Звук запускается только после жеста пользователя; в тестах он создаётся по первому клику.
