# Game Prompt Forge

Скилл для [Claude Code](https://claude.com/claude-code) (подходит и для Codex), который превращает идею игры в одно-три предложения в **один большой самодостаточный промпт**. Вы копируете этот файл в новый чат в пустой папке, и Claude сам, без дополнительных вопросов, делает полностью играбельную, отполированную игру.

Скилл не пишет саму игру. Он пишет **задание**: точное в том, что определяет игру, и свободное во всём остальном, чтобы исполнитель не застревал и не ограничивался каркасом.

## Пример

Вы пишете:

> Сделай промпт для игры: tower defense про магическую школу

Скилл задаёт 2–4 коротких вопроса (платформа, длительность сессии, стиль, язык), принимает все остальные решения сам и сохраняет файл `<название>-prompt.md`. Дальше вы открываете новый чат в пустой папке, вставляете содержимое файла, и игра собирается за один заход.

## Что делает скилл

1. **Разбирает идею.** Определяет жанр, тон, камеру. Выделяет то, что вы уже решили, и то, что остаётся на него.
2. **Задаёт вопросы.** Не больше четырёх за раз, только поверхностные: платформа, стиль, референсы, язык. Механики, числа и баланс он решает сам.
3. **Принимает дизайн-решения.** Опоры игры, главный цикл, «сердце» игры, прогрессия, темп, арт и звук. Выбирает движок (по умолчанию браузерная игра на TypeScript + Vite).
4. **Собирает промпт** по проверенному скелету: автономия исполнителя, порядок вертикальных срезов, архитектура с отладочным API для сквозного теста, числа в таблицах, приоритеты и чек-лист готовности.
5. **Проверяет «холодным читателем»**: противоречия в числах, тупики в прогрессии, размытые слова без измеримого критерия.
6. **Выдаёт результат**: один файл, краткий список принятых решений и инструкцию по запуску.

Если идея опирается на чужую франшизу, скилл сохраняет жанр и дух, но требует оригинальные названия, персонажей и ассеты, чтобы игру можно было публиковать.

## Установка

Скопируйте репозиторий в папку скиллов.

**Claude Code**

```bash
git clone https://github.com/iHoooK/game-prompt-forge.git ~/.claude/skills/game-prompt-forge
```

**Codex**

```bash
git clone https://github.com/iHoooK/game-prompt-forge.git ~/.codex/skills/game-prompt-forge
```

На Windows `~` — это папка пользователя (`C:\Users\<имя>`). Затем перезапустите Claude Code или Codex. Для обновления выполните `git pull` в папке скилла.

## Как пользоваться

Скилл срабатывает на просьбы вроде:

- «сделай промпт для игры»
- «напиши ТЗ, чтобы Claude сделал игру»
- «хочу игру в стиле X про Y»
- «придумай и опиши игру для генерации»

Он не нужен, если вы хотите получить саму игру прямо сейчас в этом чате или правите код существующей игры.

## Структура

| Файл | Назначение |
|---|---|
| `SKILL.md` | Инструкция для агента: принципы и рабочий процесс |
| `references/design-method.md` | Метод проектирования игры: опоры, цикл, «сердце», числа |
| `references/genre-notes.md` | Заметки по жанрам: что обязательно и типовые провалы |
| `references/engines.md` | Выбор движка и платформы |
| `references/intake-questions.md` | Список кандидатов для вопросов пользователю |
| `references/prompt-template.md` | Скелет итогового промпта с пояснениями |
| `references/example-oreflow.md` | Разбор эталонного промпта браузерной игры Oreflow |
| `references/pitfalls.md` | Ловушки, взятые из реальных прогонов |
| `references/quality-checklist.md` | Чек-лист проверки промпта |

## Советы

- Чем короче идея, тем больше решений принимает скилл. Если у вас есть референсы (скриншоты, названия игр), укажите их: скилл опишет их словами прямо в промпте, чтобы они не потерялись при копировании.
- Не редактируйте промпт вручную по кусочкам. Если нужны правки, попросите скилл переписать файл целиком.
- Если игра получилась не такой, как вы хотели, поправьте идею и пересоберите промпт, а не латайте результат.
