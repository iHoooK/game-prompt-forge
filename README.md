# Game Prompt Forge

> Сделано в [Promptix](https://promptix.ru) — [об авторе и поддержке](#об-авторе) ниже.

Скилл для [Claude Code](https://claude.com/claude-code) (подходит и для Codex), который превращает идею игры в одно-три предложения в **один большой самодостаточный промпт**. Вы копируете этот файл в новый чат в пустой папке, и Claude сам, без дополнительных вопросов, делает полностью играбельную, отполированную игру.

Скилл не пишет саму игру. Он пишет **задание**: точное в том, что определяет игру, и свободное во всём остальном, чтобы исполнитель не застревал и не ограничивался каркасом.

## Пример

Вы пишете:

> Сделай промпт для игры: tower defense про магическую школу

Скилл проводит интервью: несколько раундов вопросов про жанр, камеру, стиль графики, звук, управление, размах и платформу. Мелочи решает сам. В конце пересказывает игру и просит подтвердить, затем сохраняет файл `<название>-prompt.md`. Дальше вы открываете новый чат в пустой папке, вставляете содержимое файла, и игра собирается за один заход.

## Что делает скилл

1. **Разбирает идею.** Определяет жанр, тон, камеру. Выделяет то, что вы уже решили, и то, что остаётся на него.
2. **Проводит интервью.** Раундами по 2–4 вопроса, без ограничения общего числа: платформа, камера, визуальный стиль, звук, управление, размах, референсы, язык, чего точно не должно быть. Мелочи, числа и баланс он решает сам. Заканчивает кратким пересказом игры на подтверждение.
3. **Принимает дизайн-решения.** Опоры игры, главный цикл, «сердце» игры, прогрессия, темп, арт и звук. Выбирает движок (по умолчанию браузерная игра на TypeScript + Vite). Для графики и звука задаёт порядок: сначала скачать подходящие бесплатные ассеты с проверкой лицензии, затем сгенерировать через Codex (если доступен), процедурный вариант только запасной.
4. **Собирает промпт** по проверенному скелету: автономия исполнителя, порядок вертикальных срезов, архитектура с отладочным API для сквозного теста, числа в таблицах, приоритеты, контроль качества (скриншоты всех состояний, прохождение реальным вводом, поиск багов, ревью кода) и чек-лист готовности.
5. **Проверяет «холодным читателем»**: противоречия в числах, тупики в прогрессии, размытые слова без измеримого критерия.
6. **Выдаёт результат**: один файл, краткий список принятых решений и инструкцию по запуску.

Дополнительно: режим **доработки** (если прошлая игра вышла не такой, скилл разбирает претензии и собирает промпт-исправление), режимы объёма, жанровые рецепты и разведка бесплатных ассетов при написании промпта.

Если идея опирается на чужую франшизу, скилл сохраняет жанр и дух, но требует оригинальные названия, персонажей и ассеты, чтобы игру можно было публиковать.

## Установка

Скопируйте репозиторий в папку скиллов.

**Claude Code**

```bash
git clone https://github.com/iHoooK/game-prompt-forge.git ~/.claude/skills/game-prompt-forge
```

**Codex**

```bash
git clone https://github.com/iHoooK/game-prompt-forge.git ~/.codex/skills/game-prompt-forge
```

На Windows `~` — это папка пользователя (`C:\Users\<имя>`). Затем перезапустите Claude Code или Codex. Для обновления выполните `git pull` в папке скилла.

## Как пользоваться

Скилл срабатывает на просьбы вроде:

- «сделай промпт для игры»
- «напиши ТЗ, чтобы Claude сделал игру»
- «хочу игру в стиле X про Y»
- «придумай и опиши игру для генерации»

Он не нужен, если вы хотите получить саму игру прямо сейчас в этом чате или правите код существующей игры.

## Советы

- Чем короче идея, тем больше решений принимает скилл. Если у вас есть референсы (скриншоты, названия игр), укажите их: скилл опишет их словами прямо в промпте, чтобы они не потерялись при копировании.
- Не редактируйте промпт вручную по кусочкам. Если нужны правки, попросите скилл переписать файл целиком.
- Если игра получилась не такой, как вы хотели, поправьте идею и пересоберите промпт, а не латайте результат.

## Как помочь улучшить скилл

Скилл умеет записывать у вас локально, где правила не подошли: новый жанр, исключение, пробел. Записи лежат в папке `.game-prompt-forge` в вашей домашней папке (на Windows `%USERPROFILE%\.game-prompt-forge`), не пропадают при обновлении скилла и используются в следующих сессиях. **Ничего не отправляется автоматически.** В конце сессии скилл предложит собрать замечания для автора, а вы решаете, отправлять ли: [создать замечание на GitHub](https://github.com/iHoooK/game-prompt-forge/issues/new/choose) или переслать текст в Telegram.
